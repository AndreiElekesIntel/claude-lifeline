About

How Lifeline actually resumes a session.

The mechanism

Claude Code fires a StopFailure event when an API error ends a turn, rather than the normal Stop. Lifeline registers a hook on that event with asyncRewake enabled. When the hook exits with code 2, Claude Code injects the hook's message into the conversation and wakes the model — so the session continues on its own.

Because that happens inside Claude Code's own process, recovery does not depend on this app. You can quit the tray and every session stays protected.

Why some failures are not retried

A rate limit clears on its own, so waiting and resuming is the right move. An invalid API key or an exhausted balance fails identically on every attempt — retrying those burns the attempt budget and buries the one message that says what to fix. Those classes are reported instead.
