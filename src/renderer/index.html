How a session gets rescued

    Design rules

    Why some failures are never retried

    A rate limit clears on its own, so waiting and resuming is right. A wrong API key fails identically every time — retrying it burns the attempt budget and buries the one message that says what to fix.

    Files & locations

    Everything Lifeline writes lives under your own profile. Click any row to open it.

    Open source

    Claude Lifeline is MIT licensed and developed in the open. Read the code that watches your sessions, file an issue, or send a pull request.

    AndreiElekesIntel/claude-lifeline

    Nothing here phones home. Every number on the Analytics tab is computed on this machine from files Claude Code already wrote, and the app makes no network requests at all — the source is public so you can verify that rather than take our word for it.

    Built with Claude Opus 5 in Claude Code

    Every line of this app — the recovery hook, the analytics engine, the tests, and this page — was written with Claude Opus 5 inside Claude Code. Which makes it a tool built in the thing it protects: the failures it recovers from are ones it hit while being written.
